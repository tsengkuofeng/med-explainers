# 從 PCOS 到 PMOS

2026 年 6 月 Lancet 全球共識，多囊性卵巢症候群（PCOS）正式更名為
**Polyendocrine Metabolic Ovarian Syndrome（PMOS）**。

這是一頁互動式衛教說明，核心是澄清一個七十年的誤會：
超音波上那些「囊腫」，其實是發育停滯的卵泡。

## 內容

- 可切換的超音波示意圖（你以為看到的 / 實際上是什麼）
- 新舊名稱逐字拆解，點開看各自代表什麼
- 什麼變了、什麼沒變（診斷標準沒有改變）
- 「代謝」不等於「你的錯」
- 三年過渡期時間軸與常見問題
- 「給病人 / 給醫學生」兩種閱讀深度

## 放上 GitHub Pages

1. 把 `index.html` 推上 repo
2. Settings → Pages → Source 選 `main` 分支的根目錄
3. 幾分鐘後網址會是 `https://<你的帳號>.github.io/<repo 名稱>/`

單一 HTML 檔，無相依套件，字型從 Google Fonts 載入。
超音波影像由 canvas 即時繪製，非真實臨床影像。
